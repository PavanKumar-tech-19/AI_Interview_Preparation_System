# 🤖 AI Interview Preparation System

A professional AI-powered Interview Preparation System built using **Python, Flask, SQLite, and Google Gemini AI**. The application helps users practice technical interviews with AI-based evaluation, interview history, dashboard analytics, resume-based mock interviews, and PDF reports.

---

## ✨ Features

- 🔐 User Registration & Login
- 💻 Domain-Based Mock Interviews
- 🎲 Random Interview Questions
- 🤖 AI Answer Evaluation using Google Gemini
- 📊 User Dashboard & Performance Analytics
- 📜 Interview History
- 📄 PDF Report Generation
- 📁 Resume Upload
- 🧠 Resume-Based Interview Questions
- 👨‍💼 Admin Dashboard
- 🎨 Professional Responsive UI

## 🚀 Installation

1. Clone the repository

```bash
git clone https://github.com/PavanKumar-tech-19/AI_Interview_Preparation_System.git
```

2. Move into the project folder

```bash
cd AI_Interview_Preparation_System
```

3. Create a virtual environment

```bash
python -m venv venv
```

4. Activate the virtual environment

**Windows**

```bash
venv\Scripts\activate
```

5. Install dependencies

```bash
pip install -r requirements.txt
```

6. Add your Gemini API Key in a `.env` file

```
GEMINI_API_KEY=YOUR_API_KEY
```

7. Run the project

```bash
python app.py
```
